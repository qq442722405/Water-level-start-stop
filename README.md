# 水位数字自动控制

Windows 软件，通过 OCR 识别屏幕上的水位数字，并自动点击两个指定控制点。

## 工作逻辑

例如：

- 高水位阈值：2.5
- 低水位阈值：2.0
- 检测间隔：1 秒

当：

`水位 > 2.5`

软件每隔 1 秒检查一次，满足条件就点击“高水位点击点”。

当：

`水位 < 2.0`

软件每隔 1 秒检查一次，满足条件就点击“低水位点击点”。

使用上下两个阈值形成滞回区，避免 2.5 附近来回抖动造成两个动作互相切换。

## 使用方法

1. 启动程序。
2. 点击“框选识别区域”。
3. 在屏幕上框住水位数字，包括小数点。
4. 点击“抓取高水位点击点”，移动鼠标到对应按钮，按 F8。
5. 点击“抓取低水位点击点”，移动鼠标到对应按钮，按 F8。
6. 设置高/低阈值。
7. 设置检测间隔。
8. 设置“最小点击间隔”，这是额外的防连点保护。
9. 点击“保存配置”。
10. 点击“开始监控”。

## GitHub 在线打包

上传整个工程到 GitHub 后：

Actions → Windows EXE Build → Run workflow

成功后：

Artifacts → 水位数字自动控制-Windows

即可下载 EXE。

## 注意

本程序通过 Windows 鼠标模拟点击，因此需要目标网页/软件窗口允许正常鼠标操作。

如果水位数字字体、颜色或背景非常复杂，建议把识别区域尽量框小，只包含数字和小数点。
