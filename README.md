# 水位数字自动控制

Windows 水位数字 OCR 自动控制软件。

## 功能

- OCR 识别屏幕上的水位数字
- 可框选识别区域
- 高水位阈值：水位 `>` 设定值时执行高水位操作点
- 低水位阈值：水位 `<` 设定值时执行低水位操作点
- **操作间隔**：控制连续自动操作的最小间隔
- **识别安全上限**：OCR 识别结果超过该值时，本次绝不点击，用于防止 `2.5` 被误识别成 `25` 等错误导致乱点
- 高/低操作点均采用**全屏十字光标直接抓取**：点击按钮后，出现十字光标，直接点击目标位置即可；右键取消
- 保存配置时同时保存软件窗口大小，下次启动自动恢复
- 目录版 EXE，不使用 onefile，降低 ONNX Runtime DLL 加载问题
- GitHub Actions 仅手动触发在线打包

## 示例

高水位阈值：`2.5`

低水位阈值：`2.0`

操作间隔：`5` 秒

识别安全上限：`10`

运行时：

- `2.6` → 点击高水位操作点
- `2.7` → 如果距离上次操作不足 5 秒，不点击；达到间隔后再次满足条件才操作
- `2.3` → 不操作
- `1.9` → 点击低水位操作点
- `25` → 超过安全上限 `10`，**绝不点击**

## GitHub 在线打包

Actions 只使用 `workflow_dispatch` 手动触发：

`Actions → Windows EXE Build → Run workflow`

输出：

`水位数字自动控制-Windows.zip`

压缩包内为完整目录版程序，解压后运行 `WaterLevelAutoControl.exe`。
