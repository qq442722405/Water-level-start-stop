# 水位数字自动控制

Windows 水位数字 OCR 自动控制工具。

## 核心功能

- 框选水位数字识别区域
- ddddocr 数字识别，支持小数点
- **检测间隔**：控制多久识别一次
- **操作间隔**：控制两次自动操作之间至少间隔多久
- 高水位阈值：水位 `>` 高阈值时操作高水位点
- 低水位阈值：水位 `<` 低阈值时操作低水位点
- 高/低水位操作点采用全屏十字光标，直接鼠标点击抓取
- **识别安全**：支持 `>`、`>=`、`<` 三种拦截条件，命中后绝不点击
- **识别调整**：可调整放大倍数、预处理模式、阈值、降噪、对比度、亮度、锐化、黑白反转，并实时查看原图/处理图和 OCR 结果
- 保存配置同时保存窗口大小
- GitHub Actions 仅手动触发在线打包
- Windows 目录版 EXE，不使用 onefile

## 推荐参数

例如实际水位正常在 2.0～2.5：

- 高水位：2.5
- 低水位：2.0
- 检测间隔：1 秒
- 操作间隔：5 秒
- 识别安全：`>` 10

如果 OCR 偶尔把 `2.5` 识别成 `25`，安全规则 `> 10` 会阻止这次误操作。
